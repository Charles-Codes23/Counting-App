# Counting App
This is a simple counting app built with HTML, CSS, and JavaScipt that allows users to increase, decrease, and reset a counter to zero.

## Features
- Increase the counter
- Decrease the counter
- Reset the counter to Zero

## Technologies Used
- HTML
- CSS
- JavaScript

## Purpose
This project was created to practise JavaScript variables, functions, event handling, and DOM manipulations.
